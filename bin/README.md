## How to run in VS Code
1. Unzip, then File > Open Folder > select `Tutorial5B`.
2. Install "Extension Pack for Java" if prompted (needs JDK 8+).
3. Open any .java file and click **Run** above `main`,
   or go to Run and Debug (Ctrl+Shift+D) and pick e.g. "Q6 - SimpleCalculator".

## Terminal alternative
    javac *.java
    java SimpleCalculator
